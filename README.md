# Windows Server & Active Directory Labs

This repository documents my hands-on practice with Windows Server administration, Active Directory, networking, and IT support troubleshooting.

The labs are designed to develop practical skills relevant to entry-level IT Support, Service Desk, and Junior IT Administrator roles.

## Lab Environment

- Windows Server 2022 Standard Evaluation
- Oracle VirtualBox
- Windows 10 Host
- Virtual Networking (NAT and isolated lab networks)
- Active Directory Domain Services (upcoming labs)

## Learning Goals

Develop practical experience in Windows Server administration, user and group management, authentication troubleshooting, Group Policy, DNS, and IT infrastructure support.
